      ⚖️ Ethical Use Policy

      CyberSec Academy is a strictly educational platform for learning ethical cybersecurity and penetration testing concepts.

      Permitted Uses

      • Learning cybersecurity concepts and techniques for defensive purposes
      • Practicing on systems you personally own or control
      • Authorized penetration testing with explicit written permission
      • Preparing for certifications (CEH, Security+, OSCP)
      • Coordinated Vulnerability Disclosure (CVD) programs

      Prohibited Uses

      • Unauthorized access to any computer system, network, or device
      • Any activity that violates local, national, or international law
      • Deploying malware, ransomware, or destructive tools
      • Privacy violations or unauthorized data collection

      Legal Framework

      Unauthorized computer access is illegal under:

      • Computer Fraud and Abuse Act (CFAA) — United States
      • Computer Misuse Act 1990 — United Kingdom
      • EU Directive 2013/40/EU — European Union
      • Equivalent cybercrime laws worldwide

      Curriculum Alignment

      This curriculum is aligned with industry standards:

      • EC-Council Certified Ethical Hacker (CEH)
      • CompTIA Security+
      • OWASP Testing Guide
      • NIST Cybersecurity Framework
      • CISA (Cybersecurity and Infrastructure Security Agency) guidelines

      Report vulnerabilities responsibly via Coordinated Vulnerability Disclosure (CVD). Reference: CISA CVD Process
